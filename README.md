# Лабораторная работа 1. Поиск по каталогу

## Вариант

`airports-csv | all | fold | words-all | top10 | mark | boost`

## Запуск

Требуется Python 3. Запустите терминал в этой папке и выполните:

```bash
python main.py
```

Затем загрузите каталог:

```text
load airports.csv
```

В папке находятся `main.py` и набор данных `airports.csv` (файл, предоставленный для задания).

## Реализованные команды

- `help` — список команд.
- `load <файл.csv>` — загрузить CSV-каталог. Новая загрузка очищает фильтры, оценки и предыдущие результаты.
- `fields` — поля, типы данных и допустимые операторы фильтрации.
- `show` — показать все записи и все поля; фильтры не влияют на эту команду.
- `filter add <поле> <оператор> <значение>` — добавить фильтр. Все фильтры применяются одновременно.
- `filter list` — список фильтров.
- `filter remove <номер>` — удалить фильтр по номеру.
- `filter clear` — очистить все фильтры.
- `search "<запрос>"` — поиск по `title`, `city`, `keywords`.
- `save <файл>` — сохранить последние показанные результаты поиска в текстовый файл.
- `rate <id> <1..5>` — сохранить оценку записи в памяти до выхода или следующей загрузки.
- `ratings` — показать выставленные оценки.
- `exit` — завершить программу.

## Правила варианта

- `fold`: поиск без учёта регистра с помощью `casefold()`.
- `words-all`: каждое слово запроса должно присутствовать хотя бы в одном из поисковых полей.
- `top10`: выводится не более десяти записей; число «Найдено» отражает все записи, прошедшие фильтры и поиск.
- `mark`: совпавшие слова в поисковых полях выделяются как `[[слово]]`.
- `boost`: оценка влияет на порядок результатов, но не меняет релевантность. Баллы = релевантность + 0.5 × оценка, если оценка есть.
- Релевантность рассчитывается по словам запроса: совпадение слова в `title` даёт 3 балла, в `city` — 1 балл, в `keywords` — 1 балл. Если запрос пустой, релевантность равна 0, а результаты определяются фильтрами.
- Если запрос пустой, поиск возвращает записи, прошедшие фильтры.
- Оценки хранятся в памяти и сбрасываются при новой загрузке.
- Ошибки команд выводятся сообщением и не завершают программу.

## Типы полей и фильтры

- Текстовые поля: `eq`, `ne`, `contains`.
- Числовые поля (`elevation_ft`, `latitude`, `longitude`): `eq`, `ne`, `lt`, `le`, `gt`, `ge`.
- Логическое поле (`scheduled`): `eq`, `ne`; значения `true` и `false`.
- Пустые значения не проходят фильтр.

## Примеры

```text
load records.csv
fields
show
search "bOsToN"
filter add country eq US
filter add scheduled eq false
filter list
search "Boston"
rate US-0960 5
ratings
save result.txt
exit
```

## Примечание

Скоринг релевантности и формула boost зафиксированы в этом README, поскольку в задании они должны быть определены и описаны автором реализации.

*Алгоритм работы программы
Запуск программы. Инициализируются переменные для записей, фильтров, оценок и результатов поиска.
Загрузка данных. Пользователь вводит команду load airports.csv. Программа проверяет структуру CSV-файла и преобразует данные в нужные типы.
Ввод команды. Пользователь выбирает действие: поиск, фильтрация, просмотр записей, оценивание или сохранение результатов.
Обработка запроса. Программа нормализует поисковые слова, проверяет фильтры и ищет записи, содержащие все слова запроса, в полях title, city и keywords.
Ранжирование результатов. Совпадения в названии аэропорта оцениваются в 3 балла, в городе и ключевых словах — в 1 балл. Пользовательская оценка дополнительно влияет на порядок сортировки.
Вывод результатов. Программа сортирует записи, показывает максимум 10 результатов и время поиска.
Сохранение и завершение. Пользователь может сохранить результаты в файл или продолжить работу. Команда exit завершает программу.
